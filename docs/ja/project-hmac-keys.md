# HMACキーの保持

対象はJSON-PROJECTS-HMACKEYS-001〜005で、状態はPARTIALのままです。
契約の正本は[英語版](../en/slices/project-hmac-keys.md)です。

削除したキーの秘密情報は、削除トランザクション内で消去します。
DELETED状態のメタデータは、プロジェクトごとに更新時刻とアクセスIDで並べた最新128件を保持します。
それより古いものは次の削除時に回収し、getは404になります。
これはローカルの件数制限です。Cloud Storageの公式仕様は`showDeletedKeys`を定めていますが、保持期間は保証していません。
有効なキーの上限である、プロジェクト・サービスアカウントごとの10件には影響しません。
