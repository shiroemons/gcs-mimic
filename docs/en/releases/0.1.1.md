# gcs-mimic 0.1.1

0.1.1 is the first release with a container image:
`ghcr.io/shiroemons/gcs-mimic:0.1.1` for `linux/amd64` and `linux/arm64`.
It also ships the four Linux archives and `SHA256SUMS`. Application behavior is
unchanged from 0.1.0; its included workflows, compatibility notes, platform
verification and known limitations all apply. See the
[0.1.0 release notes](https://github.com/shiroemons/gcs-mimic/blob/v0.1.0/docs/en/releases/0.1.0.md).

## Changes

- Container publication accepts the SLSA v1 provenance that BuildKit 0.34
  records. The v0.1.0 container step rejected valid images on this check, so
  **0.1.0 has no container image**; use 0.1.1.
- A resumable-upload test gives catalog admission enough time on loaded CI
  runners. Test-only change.

## Compatibility and migration

No migration from 0.1.0 is required. The data-directory schema remains
`PRAGMA user_version = 21`; 0.1.0 and 0.1.1 read and write the same data
directories. Follow the 0.1.0 notes for fake-gcs-server migration and backups.

## Verification

The [release workflow](https://github.com/shiroemons/gcs-mimic/blob/v0.1.1/.github/workflows/binaries.yaml)
creates this Release only after `validate`, Foundation and the four native Linux
build/test jobs succeed at the tag's SHA. The
[container workflow](https://github.com/shiroemons/gcs-mimic/blob/v0.1.1/.github/workflows/ghcr.yaml)
then builds both architectures natively, verifies their SBOM and provenance,
publishes the multi-architecture tag and checks anonymous pulls.
