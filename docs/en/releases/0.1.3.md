# gcs-mimic 0.1.3

0.1.3 adds native Windows archives for x86-64 (`x86_64-pc-windows-msvc`) and
ARM64 (`aarch64-pc-windows-msvc`), so every supported target now ships: macOS,
Windows and Linux GNU/musl, each for ARM64 and x86-64. It also publishes
`ghcr.io/shiroemons/gcs-mimic:0.1.3` for `linux/amd64` and `linux/arm64`.
The [0.1.0 release notes](https://github.com/shiroemons/gcs-mimic/blob/v0.1.0/docs/en/releases/0.1.0.md)
describe the included workflows, compatibility and known limitations.

## Changes

- `gcs-mimic import fake-gcs-server` now detects a source file replaced during
  import on Windows even when its size, contents and modification time match.
  Windows source fingerprints previously compared only size and modification
  time; they now also compare the volume, file index and change time.
- On Windows, `sync_dir` is rejected with a diagnostic that directory
  synchronization is supported on Linux and macOS only. It previously claimed
  the directory was not writable.
- Native test suites pass on Windows runners. The remaining fixes are
  test-only: process environments, file handle lifetimes during cleanup, path
  separators, file name and time range limits, and platform-specific
  connection errors.
- Release preparation requires the manual dry run, including the publish job,
  to pass on the exact commit before tagging.

## Compatibility and migration

No migration is required. The data-directory schema remains
`PRAGMA user_version = 21`, shared by 0.1.0 through 0.1.3. Windows archives
are unsigned, use the static MSVC runtime and keep the Windows recovery limits
in the 0.1.0 notes: normal restart and process termination are covered, OS
crash and power loss are not. Directory synchronization is not available on
Windows.

## Verification

The [release workflow](https://github.com/shiroemons/gcs-mimic/blob/v0.1.3/.github/workflows/binaries.yaml)
creates this Release only after `validate`, Foundation and all eight native
build/test jobs succeed at the tag's SHA, including Windows runtime import
checks. The
[container workflow](https://github.com/shiroemons/gcs-mimic/blob/v0.1.3/.github/workflows/ghcr.yaml)
then builds both Linux architectures natively, verifies their SBOM and
provenance, publishes the multi-architecture tag and checks anonymous pulls.
