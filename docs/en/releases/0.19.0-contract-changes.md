# 0.19.0 public contract changes

<!-- markdownlint-configure-file {"MD013": false} -->

Draft release notes for the contract changes before the 1.0.0 freeze.

## The `scheme` default serves HTTP and HTTPS on one port

The default `scheme` changes from `https` to the new value `auto`. An `auto` listener reads the first byte of each connection without consuming it: a TLS handshake record selects TLS, anything else plain HTTP. HTTPS clients keep working on the same port with the same certificate, and plain HTTP clients, such as SDKs given `STORAGE_EMULATOR_HOST`, now connect without a setting.

- `http`, `https` and `both` keep their meanings. `https` is how to refuse plain HTTP.
- `tls_cert` and `tls_key` choose the certificate only; they do not make the listener HTTPS-only.
- The default is `auto` under every `auth_mode` and `compat_profile`.
- A Unix socket serves plain HTTP under `auto`, so `unix_socket` needs no `scheme`; `https`, `both` and TLS settings beside it fail startup.
- fake-gcs-server's `--public-host` without `--scheme` still translates to an `https://` public base.
- A connection waits for its first byte for at most `header_read_timeout_ms` from accept, and the TLS handshake limit also counts from accept. A connection closed before its first byte, such as a TCP probe, emits no diagnostic.
- No response redirects between the protocols or sends `Strict-Transport-Security`.

| If you | Then |
| --- | --- |
| Rely on plain HTTP being refused | Set `scheme=https`. |
| Pass `tls_cert` and `tls_key` without `scheme` and want HTTPS only | Set `scheme=https`; otherwise plain HTTP is served too. |
| Read `scheme` in the ready event | Expect `auto`; `listeners[0].scheme` becomes `http`. |
| Use links produced without an explicit `api_base_url` and without a usable request authority, including the ready event's `api_base_url` | They change from `https://` to `http://`. Set `api_base_url` to keep HTTPS links. |
| Set `scheme=http` only because of the old default | It can be removed; keeping it refuses HTTPS, as before. |
| Set `scheme=http` together with `unix_socket` | The scheme can be removed. |

Configurations that set `--scheme http` or `--scheme https`, and HTTPS clients of the default, need no change. Without `--url`, `gcs-mimic healthcheck` probes an `auto` server over plain HTTP, so it needs no CA. JSON links and the resumable-upload session URL already followed each request's own scheme and authority without an explicit `api_base_url`; under `auto` that scheme is the one the connection used.

The published recipes and examples keep `GCS_MIMIC_SCHEME: http` while they pin a release before 0.19.0; the release that ships this change drops it. See the [design](../slices/single-port-scheme.md).
