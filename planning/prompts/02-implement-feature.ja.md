# 機能単位で進めるプロンプト

```text
gcs-mimicの共通実装プロンプトとAGENTS.mdに従い、次の機能だけを実装してください。

対象機能ID: <FEATURE_IDS>

台帳、依存関係、現状のコード、対象の最新公式仕様を確認してください。
docs/en/dependency-policy.mdに従ってRustと選択した依存の最新安定版を確認し、必要な更新を実施・検証してください。採用した具体的な版はlockfile等に記録し、阻害要因があれば明示してください。
不足する必須依存は最小限だけ追加し、正常系・異常系・境界値・権限・関係する他機能を受け入れ条件に分解してください。
通信の入力→状態遷移→応答までを完成させ、関連する公式SDKと必要な競合・再起動・資源使用量の確認を行ってください。
getting-started-spec.mdで該当する利用手順を実際に通し、英語の説明とコマンドを更新してください。

全条件を満たした行だけIMPLEMENTEDにし、残る場合はPARTIALとして未対応ケースを具体的に書いてください。
compatibility/features.jsonに実際の証拠を保存し、英語の表を再生成してください。
コード、コメント、コミット、プロジェクト文書は英語にしてください。
完了報告は日本語で、変更ID、確認結果、制限、次の実装単位を示してください。
この機能と必要な依存が完了したら終了してください。
```
