# 低メモリ・低CPUの検証

```text
gcs-mimicの資源使用量を、docs/en/design.mdの条件に沿って測定してください。
対象は実装済みの機能と、固定した認証/TLS/保存方式/耐障害性プロファイルだけにしてください。

本文サイズ、同時実行数、メタデータ件数、OS/CPU/メモリ制限、ビルド設定、SDKと比較対象イメージのバージョンを記録してください。
RSSとページキャッシュを含むコンテナメモリ、CPU秒/GiB、RPS、転送量、p50/p95/p99、エラー率、一時ディスク量を区別してください。
負荷生成側の資源はサーバーに加算しないでください。
同じ意味の処理・同じ制約でfake-gcs-serverと比較し、チェックサムや認可を省いた高速化を同等条件の改善として扱わないでください。

具体的に測定されたボトルネックだけを改善し、必要な回帰確認と再測定を行ってください。
実測していない数値を埋めず、仮の目標を実績として表現しないでください。
英語の測定レポートと台帳の証拠を更新し、結果と改善判断を日本語で報告してください。
```
